# BookBot - Телеграм бот для чтения книг

## 📖 Описание проекта

**BookBot** - это Telegram бот, разработанный на Python с использованием фреймворка Aiogram 3.x, который позволяет пользователям читать книгу "Марсианские хроники" Рэя Брэдбери прямо в Telegram.

### Основные возможности:

- 📚 **Чтение книги по страницам** с удобной пагинацией
- 🔖 **Система закладок** для сохранения любимых страниц
- 📱 **Интуитивный интерфейс** с инлайн-клавиатурами
- 👥 **Многопользовательская поддержка** с персональными данными
- 🎯 **Удобное меню команд** в Telegram

## 🚀 Функционал

### Команды бота:

- `/start` - Запуск бота и приветствие
- `/help` - Справка по работе бота
- `/beginning` - Переход к первой странице книги
- `/continue` - Продолжить чтение с последней страницы
- `/bookmarks` - Просмотр списка закладок

### Возможности интерфейса:

- **Навигация по страницам**: Кнопки "<<" и ">>" для перелистывания
- **Добавление закладок**: Нажатие на номер страницы сохраняет её в закладки
- **Управление закладками**: Просмотр, редактирование и удаление закладок
- **Главное меню**: Быстрый доступ к основным командам через меню Telegram

## ⚙️ Установка и запуск

### Предварительные требования:

1. **Python 3.12** или выше
2. **Telegram Bot Token** от [@BotFather](https://t.me/BotFather)

### Шаги установки:

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd BookBot/Book
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv env
   source env/Scripts/activate  # Для Windows
   # или
   source env/bin/activate     # Для Linux/Mac
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**

   Создайте файл `.env` в корневой директории проекта:

   ```env
   BOT_TOKEN=your_bot_token_here
   ADMIN_IDS=123456789,987654321  # ID администраторов через запятую
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```

## 📊 Структура данных

### База данных пользователей:

```python
users_db = {
    user_id: {
        'page': int,        # Текущая страница чтения
        'bookmarks': set()  # Множество сохраненных страниц
    }
}
```

### Формат книги:

Книга представлена в виде словаря, где:
- **Ключ**: номер страницы (int)
- **Значение**: текст страницы (str)

Размер страницы: ~1050 символов с учетом пунктуации.

## 🔧 Настройка

### Конфигурация:

- **BOT_TOKEN**: Токен Telegram бота
- **ADMIN_IDS**: Список ID администраторов (через запятую)

### Параметры книги:

- **PAGE_SIZE**: Размер страницы в символах (по умолчанию: 1050)
- **BOOK_PATH**: Путь к файлу книги (по умолчанию: 'book/book.txt')

## 📝 Использование

1. **Запустите бота командой** `/start`
2. **Ознакомьтесь со справкой** через `/help`
3. **Начните чтение** с `/beginning` или продолжите с `/continue`
4. **Добавляйте закладки**, нажимая на номер страницы
5. **Управляйте закладками** через `/bookmarks`
